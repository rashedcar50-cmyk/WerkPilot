# WerkPilot v0.1.1

أول نسخة تشغيلية محلية من WerkPilot لإدارة ورشة السيارات.

## التشغيل
1. ثبّت Node.js 18 أو أحدث (اختياري للتشغيل المحلي).
2. افتح المجلد في Terminal.
3. نفّذ: `npm start` أو افتح `index.html` مباشرة.
4. أو استخدم النسخة المنشورة: https://rashedcar50-cmyk.github.io/WerkPilot/

## بيانات الدخول التجريبية
- المدير: `admin` / `1234`
- المحاسب: `accountant` / `1234`
- الميكانيكي: `mechanic` / `1234`
- المستودع: `warehouse` / `1234`

## تحديثات قسم المشتريات (v0.1.1)
- توحيد نموذج البيانات (مورد، رقم فاتورة، تاريخ، إجمالي، حالة، رابط المستند)
- جدول أوضح مع إحصائيات سريعة
- تصوير / رفع فاتورة مع محاولة OCR عبر Supabase
- رفع تلقائي للإيصالات إلى bucket `purchase-receipts`
- عرض المستند مباشرة
- إضافة شراء يدوي محسّنة
- إمكانية حذف فاتورة
- فتح كاميرا اللابتوب لتصوير الفاتورة

## ملاحظات مهمة
- هذه نسخة تشغيلية أولية تحفظ البيانات محلياً في المتصفح عبر localStorage.
- رفع الإيصالات يستخدم Supabase Storage.
- لا يوجد ربط حقيقي حالياً مع البنك أو TSE أو PartsLink24 أو MATIS؛ توجد نقاط تكامل جاهزة في الواجهة فقط.
- قراءة ورقة تسجيل السيارة تسمح بالتصوير/الرفع، وOCR الحقيقي يعتمد على Edge Functions.
- هذه النسخة ليست بديلاً عن مراجعة محاسب أو مستشار ضريبي.

## Supabase (البيانات السحابية)

1. افتح مشروعك في Supabase → **SQL Editor**
2. الصق محتوى الملف `supabase-schema.sql` ونفّذه (Run)
3. تأكد أن bucket اسمه `purchase-receipts` موجود (Public)
4. بعد التنفيذ: المشتريات تُحفظ محلياً + على Supabase

بدون تنفيذ الـ SQL، التطبيق يشتغل عادي على localStorage.
