# WerkPilot Pro v0.2

نظام إدارة ورشة سيارات (عربي / RTL) — نسخة تشغيلية.

## التشغيل
- الموقع: https://rashedcar50-cmyk.github.io/WerkPilot/
- أو محلياً: افتح `index.html` / `npm start`

## ما تم في v0.2
- مشتريات محسّنة: معاينة قبل الحفظ، OCR أسرع مع ضغط الصورة، كاميرا، PDF/عرض
- مزامنة سحابية عبر Supabase: مشتريات + عملاء + مخزون
- ربط المشتريات بالمخزون (زيادة الكمية تلقائياً)
- بيانات تجريبية جاهزة (عملاء، سيارات، مخزون، فواتير)
- تصدير نسخة احتياطية JSON من الإعدادات
- زر مزامنة من السحابة

## Supabase
- نفّذ أعمدة الجداول + سياسات RLS من `supabase-schema.sql` (تم على المشروع)
- Bucket: `purchase-receipts` (Public) لرفع الإيصالات

## ملاحظات
- البيانات تُحفظ في localStorage + تُرسل للسحابة عند التوفر
- التكاملات الخارجية (PartsLink24 / TSE / بنك) واجهات فقط حالياً
- ليست بديلاً عن استشارة محاسبية للامتثال الألماني
