# WerkPilot v0.1

أول نسخة تشغيلية محلية من WerkPilot لإدارة ورشة السيارات.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح المجلد في Terminal.
3. نفّذ: `npm start`
4. افتح: `http://127.0.0.1:4173`

## بيانات الدخول التجريبية
- المدير: `admin` / `1234`
- المحاسب: `accountant` / `1234`
- الميكانيكي: `mechanic` / `1234`
- المستودع: `warehouse` / `1234`

## ملاحظات مهمة
- هذه نسخة تشغيلية أولية تحفظ البيانات محلياً في المتصفح عبر localStorage.
- لا يوجد ربط حقيقي حالياً مع البنك أو TSE أو PartsLink24 أو MATIS؛ توجد نقاط تكامل جاهزة في الواجهة فقط حتى يتم إدخال بيانات وربط API/مزود مرخّص.
- قراءة ورقة تسجيل السيارة في هذه النسخة تسمح بالتصوير/الرفع وحفظ المستند، مع نموذج مراجعة للبيانات. OCR الحقيقي يحتاج خدمة OCR أو نموذج محلي في مرحلة الربط التالية.
- هذه النسخة ليست بديلاً عن مراجعة محاسب أو مستشار ضريبي للامتثال الألماني أو الإسباني.
