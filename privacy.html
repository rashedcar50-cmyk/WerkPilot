Datenschutz

BayMeister ist eine Werkstatt-App. Daten (Kunden, Fahrzeuge, Aufträge, Rechnungen) werden vorwiegend lokal im Browser gespeichert. Optional erfolgt eine Synchronisation mit Supabase, sofern konfiguriert.

Es werden keine Werbenetzwerke eingebunden. Fahrzeugschein-Fotos können zur Texterkennung an eine Edge-Funktion gesendet werden, wenn diese aktiv ist.
