# Instructions for work on WerkPilot

**Read the project state reference before starting work, and update it when you finish.**

- The reference (`PROJECT_STATE.md`) lives in the owner's private repository `teiltool-intercars-sync`, branch `project-state`. It holds decisions, what is done, open problems and next steps for WerkPilot and the Teiltool shop.
- After each task add a dated line to its update log (result, tests, what remains) and update the affected sections. Keep "done" and "proposed" apart.
- Never write passwords, API keys or bank numbers into any file of this public repository.
- Tests: `node tests/run.js`. Bump the version in `index.html` and `sw.js` together.
